## 使用变化

- 前端仍可离线使用本地演示数据。
- 后端 `.env` 中设置 `API_TOKEN` 后，前端个人中心“连接受保护的 AI 服务”可输入令牌。仅驻留标签页内存，退出/删除账号时清除；不要在公开客户端内嵌令牌，也不要把同一令牌当成用户隔离。
- 后端打卡请求现在必须包含长度为 8–64 的 `request_id`。同一动作重试使用相同 ID 和内容，不同内容复用该 ID 返回 409。
- LLM_ENABLED 与模型密钥配置正确且模型支持视觉时，OCR 才能执行真实转录；模型故障不会制造示例任务。
- 部署使用 `requirements-lock.txt`。该锁文件来自本次 Windows/Python 3.12 环境，Linux 部署还应在目标环境验证。
- systemd 以 studyflow 普通账号运行，部署脚本会创建该账号并设置目录权限。
