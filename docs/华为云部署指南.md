# 学迹 StudyFlow — 华为云部署指南

> 对应提案技术路线：华为云服务器或适用的云部署服务。
> 部署完成后任何人可通过公网 IP / 域名访问，不依赖开发电脑开机。

## 零、临时分享（内网穿透，免服务器）

演示/给同学试用时，无需服务器，一条命令生成公网链接：

```bash
# 前置：前端开发服务器已运行 (cd frontend && npm run dev)

# 方式1：cloudflared（推荐，访问无需密码）
& "$env:USERPROFILE\studyflow-tools\cloudflared.exe" tunnel --url http://localhost:5173 --no-autoupdate

# 方式2：localtunnel（访问者需输入本机公网 IP 作为密码）
npx --yes localtunnel --port 5173
```

把输出的 `https://xxx.trycloudflare.com` 链接发给任何人即可访问。
注意：链接是临时的，电脑关机/进程退出即失效；正式使用请按下面步骤部署到华为云。

## 部署架构

```
浏览器 ──HTTPS──▶ 华为云 ECS
                    ├── Nginx (80/443)
                    │     ├── /        → 前端静态文件 (dist/)
                    │     └── /api     → 反向代理 → uvicorn :8000 (FastAPI)
                    ├── FastAPI + SQLAlchemy
                    └── 华为云 RDS (MySQL) / Redis(可选)
```

## 第一步：构建前端

在本机 `D:\demo\Study_Flow\frontend` 下：

```bash
npm run build
```

产物在 `frontend/dist/`（纯静态文件，可直接托管）。

## 第二步：购买/准备华为云 ECS

1. 华为云控制台 → 弹性云服务器 ECS（2核4G 即可，CentOS/Ubuntu/openEuler 均可）
2. 安全组放行端口：**80、443、8000**（8000 仅调试用，正式可只留 80/443）
3. 拿到公网 IP，如 `123.45.67.89`

## 第三步：部署前端

### 方式 A：ECS + Nginx（推荐，与后端同机）

```bash
# 上传 dist 目录到服务器（在本机 PowerShell 执行，或用 CodeArts 部署）
scp -r D:\demo\Study_Flow\frontend\dist root@123.45.67.89:/var/www/studyflow

# 服务器上安装 Nginx
sudo apt update && sudo apt install -y nginx   # Ubuntu/Debian
# 或: sudo yum install -y nginx               # CentOS/openEuler
```

Nginx 配置 `/etc/nginx/conf.d/studyflow.conf`：

```nginx
server {
    listen 80;
    server_name _;   # 或你的域名 www.xxx.com

    root /var/www/studyflow/dist;
    index index.html;

    # Vue hash 路由，直接访问根路径即可；如有 history 路由需加：
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 前端构建产物缓存
    location /assets/ {
        expires 7d;
        add_header Cache-Control "public";
    }

    # 反向代理到 FastAPI 后端(后端未部署时可注释掉，前端会自动降级规则引擎)
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

完成后访问 `http://123.45.67.89` 即可。

### 方式 B：华为云 OBS 静态网站托管（纯前端，零运维）

1. 控制台 → 对象存储服务 OBS → 创建桶（开启公共读）
2. 将 `dist/` 内全部文件上传到桶根目录
3. 桶设置 → 静态网站托管 → 开启，设置索引文档 `index.html`
4. 用托管地址（或绑定 CDN/自定义域名）访问

> 注意：纯静态托管时 `/api` 请求会失败，前端自动降级为内置规则引擎，功能完整可用；AI 对话为大模型需要后端。

## 第四步：部署后端 FastAPI（可选，接大模型需要）

```bash
# 上传 backend 目录到服务器
scp -r D:\demo\Study_Flow\backend root@123.45.67.89:/var/www/studyflow/

# 服务器上
cd /var/www/studyflow/backend
sudo apt install -y python3 python3-pip      # CentOS: sudo yum install -y python3 python3-pip
pip3 install -r requirements.txt
cp .env.example .env                          # 配置 LLM_API_KEY / DATABASE_URL
nohup uvicorn main:app --host 0.0.0.0 --port 8000 &
```

配置 `.env`：
- `LLM_ENABLED=true` + `LLM_API_KEY=sk-xxx`（华为云 ModelArts / DeepSeek / Qwen 等 OpenAI 兼容接口）
- `DATABASE_URL=mysql+pymysql://studyflow:密码@rds内网地址:3306/studyflow?charset=utf8mb4`（华为云 RDS）
- `REDIS_URL=redis://redis内网地址:6379/0`（可选）

## 第五步（可选）：域名与 HTTPS

1. 华为云购买域名并备案（国内服务器必须备案）
2. 域名解析 A 记录 → 公网 IP
3. 免费 HTTPS：`sudo apt install -y certbot python3-certbot-nginx && sudo certbot --nginx`
