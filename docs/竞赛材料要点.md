# 学迹 StudyFlow — 初赛材料要点

> 按提案要求整理：记录华为云 CodeArts 辅助开发、问题修复和部署的过程，方便写初赛材料。

## 1. 一句话定位

学迹 StudyFlow 是一款"根据真实学习结果动态改变决策"的 AI 自适应学习管家——
每次练习的正确率都会实时反哺学习计划（薄弱知识点自动触发针对性练习、减少新知识学习），
每一次调整都附带决策解释，比普通 AI 日程规划器更有说服力。

## 2. 材料中建议突出的事实

### 核心创新（对应提案图2）
- **自适应闭环**：练习打卡 → 真实正确率 → 加权更新知识点掌握度 → 重排计划 → 决策解释
- 示例数据：二叉树最近练习正确率 45% → 掌握度低于 60% 阈值 → 今日自动减少新知识、插入 40 分钟针对性练习
- 规则透明可解释：阈值 60%/85%，掌握度更新公式 = 旧值×0.5 + 正确率×0.5

## 3. 答辩可能被问的问题

1. **"自适应"和普通计划表区别？** → 普通计划一次性生成后不随执行结果变化；学迹每次打卡用真实正确率重算掌握度并重排次日计划，且输出决策解释（哪项指标触发了哪条调整）。
2. **不训练模型 AI 能力从哪来？** → 规则算法承担核心决策（阈值/加权公式可解释），大模型 API + 提示词承担自然语言理解与对话；第一版以稳定可靠为先。
3. **数据安全？** → 私有库加密存储、仅认证后可访问（Web 端以认证弹窗演示，生产接后端加密）。
4. **如何扩展？** → 前端规则引擎与后端 FastAPI 逻辑同源，切后端只需启动服务；数据库从 SQLite 切华为云 RDS 只需改 DATABASE_URL。
